# 2026-11-12 정부과제 대시보드 디자인 적용

## 승인과 범위

사용자는 정부과제 대시보드의 디자인 계획을 요청하고 별도 시안 링크를 확인한 뒤, 기존 대시보드 반영 여부를 물었다. “실제 데이터 연결과 기존 화면 적용은 남아 있다”는 답변에 “반영해줘”라고 지시했다. 이 지시를 제시한 시안의 실제 화면 적용·검증·배포 승인으로 기록한다. 추가 인터뷰가 필요한 새 제품이나 디자인 방향은 없다.

추천 시안의 밝은 배경, Pretendard, 검색 중심 배치, 4열 목록, 상세 펼침과 모바일 카드를 실제 공고에 적용한다. 기존 분야·검색·표/카드·마감 포함 기능을 유지하고 출처와 입찰 보기, 활성 필터 초기화를 연결한다. 공고 원문은 실제 저장된 주소를 사용한다.

## 판단 근거와 범위 조정

`CLAUDE.md`의 테스트 없음 안내보다 실제 Python 패키지와 테스트를 따른다. 시작 기준은 Python 3.13에서 71개 실행, 70개 통과, 유료 평가 1개 생략이다.

기존 계획의 Phase 1 전체는 아직 구현 전이다. 이번에는 화면에서 사용할 기존 날짜·상태만 보수적으로 해석한다. 한국 현재 시각으로 D-day를 계산하고 원문 종료 상태·이미 지난 마감은 종료로 표시한다. 접수 시작일·원문 검증·DB 이행·메일 날짜 규칙은 구현하지 않는다. 미래 마감만으로 접수중을 추정하지 않으며 없는 날짜와 접수 상태는 미확인으로 남긴다.

출처별 수집 실행 상태를 아직 저장하지 않으므로 정상 수집 배지를 만들지 않는다. 수집 정보에는 저장 건수와 저장된 시각의 의미만 표시한다. 한 번에 렌더링할 행을 50건으로 제한하되 전체 검색은 유지한다. 이는 HTML 다운로드 용량 개선과 별개다.

기존 배포 workflow는 수집·메일·DB 저장과 묶여 있다. 화면만 갱신할 수 있도록 읽기 전용 data checkout, 테스트, 정적 빌드, Pages 배포로 구성한 별도 workflow를 추가한다.
