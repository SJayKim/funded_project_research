# 2026-11-23 신뢰성 이슈 수정

사용자가 승인한 기준에 따라 조건부 마감은 안내, 사업별 기간 차이·상충·첨부 확인 필요는 주의로 표시한다. 원문의 기간 값이 있으나 날짜로 해석할 수 없는 경우도 검토 대상으로 남긴다. 이 분류에는 허용된 원문 호스트, 비어 있지 않은 근거, 최근 1시간 이내 확인 시각이 필요하다. 조건부·주의 공고를 날짜 확인 완료로 세지 않는다. 수집 실패·원문 접근 실패·기간 필드 부재·데이터 오류는 CI 실패를 유지한다.

나라장터와 IRIS 상세의 일시 실패는 나머지 정상 응답을 받은 뒤 실패 대상만 다시 조회한다. 출처별 공유 재시도 상한은 8회이며, 인증 실패와 접근 제한에는 재시도하지 않는다. 나라장터 전체 조회 시간 상한은 480초다. 과기정통부는 기존 실패 페이지 복구 단계에서 일시 네트워크 오류에 최대 3회 요청하며 기존 전체 시간 상한을 유지한다.

K-Startup 포털의 활용 승인과 GitHub 전용 Secret 등록 후 실제 API 인증 성공을 확인했다. API 전체 건수는 30,631건이지만 기존 기본 상한은 50페이지·5,000건이었다. 실제 GitHub 실행에서 100건 단위 조회가 161페이지에서 재시도 상한에 도달해 중단됐다. 페이지당 요청 건수를 1,000건으로 늘리고 기본 상한을 500페이지로 조정했다. 전체 시간 상한 480초와 공유 재시도 제한을 적용했다. 상한 초과나 전체 건수 불일치는 계속 실패로 보고한다. 인증키는 기록하지 않았다.

회귀 검증은 지연 복구 성공, 지속 실패 보존, 중복·총건수 변경 거부, 재시도·시간 상한 준수, 50페이지 초과 수집, 실패·주의·안내 판정을 포함한다. 운영 결과는 PR #15와 연결된 Actions 실행에서 확인한다.

나라장터는 운영 조회 도중 총건수가 바뀌는 것을 확인했다. 중간 총건수의 변화만으로 중단하지 않고, 종료 시 실제 수집 건수와 마지막 응답 총건수를 대조한다.

IRIS는 두 운영 러너에서 상세 조회 시간 초과가 발생했지만, 로컬에서 12건 모두 정상 조회됐고 별도 GitHub 러너에서도 동일 상세의 GET·POST가 모두 정상 응답했다. 세션 유지 여부에 따른 차이는 확인되지 않았다. 검증되지 않은 전송 방식 변경은 제외하고, 기존 POST와 제한된 일시 오류 복구를 유지한다. 외부 응답 실패가 지속되면 CI는 계속 실패를 표시한다.
