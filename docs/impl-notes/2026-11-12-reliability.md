- 사용자 요청: “신뢰성 제고위해 plan 세워서 진행”. 직전 감사의 날짜 불일치·수집 정체·오래된 요약을 근거로 계획 수립과 수정을 요청했다.
- 승인 범위: 확인된 신뢰성 결함 수정, 회귀 검증, 기존 구조에서의 운영 적용. 사용자 요구를 코드 수정 없이 계획서만 만드는 것으로 축소하지 않는다.
- 실행안: `docs/planning/reliability-release-2026-11-12.md`.
- 기존 작업 보호: `improve/phase-00-data-safety`에서 별도 worktree/브랜치 `improve/dashboard-reliability`를 생성했다. 원 작업 폴더의 미추적 감사·UI 계획은 수정하지 않는다.
- 사람이 결정할 새 비용·신규 출처·실제 메일 수신자는 이번 범위에 없다.

## 판단 근거

- `CLAUDE.md`의 “테스트 없음” 안내는 실제 `tests/`와 CI에 맞지 않는다. 실제 unittest discover와 Python 3.13을 따른다.
- 기존 전체 로드맵의 순차 세션 대신 최신 사용자 요청의 신뢰성 목표에 맞는 수정을 배포 단위로 묶는다. 화면 재설계는 포함하지 않는다.
- 공식 출처의 존재와 최신성은 별개다. 마지막 수집일 최댓값을 전체 정상 상태로 표시하지 않는다.

## 검증 기록

- Python 3.13: UI 통합 전 104개 실행, 103 통과·유료 평가 1 skip. 통합 후 109개 실행, 108 통과·유료 평가 1 skip. 신뢰성 전용 19개는 ResourceWarning을 오류로 설정한 상태에서도 통과했다.
- 실제 운영 DB 사본 75,221건·알림 135,770건 전수 보존, 읽기 전용 dry-run 해시 불변, 스키마 2회 이행, 정정 재실행 검증.
- 공식 원문 20건 전부 기간 확인. 알려진 날짜 오류 2건 정정, 시각 보강, 오래된 일정 발췌 숨김.
- Chromium에서 한국 자정·명시 마감시각·접수 시작·48시간 경과에 따른 자동 필터 전환, 원문 링크·검색·페이지 이동·상세 펼침·초점 복구·320/375/768/1280/1440px 확인. 콘솔 오류 없음.
- 원문 조회는 TLS 체인·호스트 검증을 켠 상태로 확인했다. 기존 CERT_NONE 경로를 제거했다.
- 기존 테스트의 지오차단 info 강제와 근거 없는 발췌 캐시는 실제 감사 결함을 보존하므로 기대값을 수정했다. 원본 발췌 보존과 검증된 캐시 유지 테스트는 유지한다.
- 신규 필드의 빈 기본값·내부 해시는 정적 HTML에 보내지 않아 같은 사본의 출력은 약 49.9MB다(수정 전 공개본 약 56.3MB). PR #2의 50건 페이지네이션을 보존했다.

## 동시 UI 변경 통합

작업 중 main에 병합된 PR #2(`23b8d487`)를 가져와 검색·상세·표/카드·페이지 이동·로컬 폰트를 유지했다. 화면 상태 객체는 공통 `status.js` 판정을 사용한다. 검증되지 않은 요약·발췌는 검색에서도 제외하고, 마감 확인 필요 필터는 날짜 누락·확인 만료·정보 상충을 포함한다.

기존 브라우저 테스트는 유효한 입력 근거 해시와 확인 시각을 가진 fixture로 보강했다. Playwright는 로컬 런타임의 설치본을 `NODE_PATH`로 지정해 실행했다. 새 패키지나 전역 설정은 설치하지 않았다.

## 운영 검증 결과

PR #3 병합 후 `health_only`로 실제 5개 출처를 점검했다. 기업마당 정상, K-Startup/나라장터 실패, 과기정통부/IRIS 부분 응답이다. 원문 20건 재확인·data 저장·Pages 배포는 성공했다. 전체 실행은 출처 장애를 드러내기 위해 마지막 단계에서 실패로 남겼다. 공개 화면의 두 마감 정정과 오래된 발췌 숨김, 공고·알림 전수 보존을 확인했다. 실행·해시·응답 범위는 [운영 상세 인계](../sessions/reliability-2026-11-12.md)에 기록했다.

출처 점검의 성공이 신규 공고 적재로 읽히지 않도록 수집 정보의 완료 문구는 “수집 응답 완료”, 건수는 “응답 N건”으로 보강했다. README의 과거 Phase 0 전용 스키마 복구 설명도 현재 추가 컬럼·검증 이력을 보존하는 안내로 갱신했다.
